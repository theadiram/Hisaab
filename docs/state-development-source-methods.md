# State source methods — two-year acquisition

12 October 2026. FY 2025–26 and FY 2026–27 to the source cutoff. These are observed source entry points, not assurances that each portal provides a complete state ledger. See the private per-state checkpoints for unchanged originals, source editions, exact failures and parsed candidates.

Use each state’s budget originals and monthly accounts to establish programme/department context; collect procurement and departmental work registers separately. Budget totals include operating expenditure, debt and transfers. Tender/contract amounts are not payments. Extracted rows, historical editions, unclear years and failed links retain their actual evidence status. Never infer a politician’s responsibility from constituency membership.

The collector reads `data/state-development-sources.json`, with a private plan override allowed in the acquisition folder. A rerun uses existing URL/hash checkpoints; `--retry-failed` is explicit. `--refresh-indexes` checks updated source listings while preserving earlier index editions and hashes. Run collection in owner order; run `--summary` after normalization. The deeper budget pass allows up to twenty observed linked PDFs at selected fiscal-edition indices; generic source homes keep the four-report limit. New database intake remains capacity-gated. Large unchanged originals stay privately on disk until hosted storage is arranged.
